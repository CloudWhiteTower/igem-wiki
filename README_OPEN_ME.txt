Auto-MC-Sensor iGEM Wiki

How to open it on Windows:

1. Unzip the whole folder.
2. Double-click START_HERE.bat.
3. A browser window will open at http://localhost:4199/.
4. Keep the black server window open while viewing the wiki.
5. Close the black server window when you are done.

If START_HERE.bat says Node.js or Python is missing, install either one and run it again:

Node.js: https://nodejs.org/
Python: https://www.python.org/

Do not open index.html directly by double-clicking it. The wiki uses local web paths, so it should be opened through the starter script.
